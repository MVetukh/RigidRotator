# RigidRotator
C++-модель квантового жёсткого ротатора.

## Возможности  

- Вычисление **энергетического спектра** ротатора  

 E_l = (ħ² / 2I) * l(l+1),   l = 0, 1, 2, ...


-  Учет **вырождений уровней** по магнитному квантовому числу $m$.  

-  Расчёт **термодинамических величин**:  
  - статистическая сумма $Z(T)$,  
  - средняя энергия $\langle E \rangle$,  
  - теплоёмкость $C_V(T)$.  

-  Моделирование **расщепления уровней** во внешнем электрическом или магнитном поле (эффект Штарка/Зеемана).  

-  Экспорт значений сферических гармоник $Y_{\ell m}(\theta, \phi)$ для построения **3D-визуализаций распределений вероятности**.
